Invoice templates — four directions

The same invoice, rendered across four design systems for the client-side builder. Each is a distinct visual identity, not a recolor: different grid, type, and signature device. All render at true US-Letter proportions from selectable HTML/CSS — the exact source the vector PDF is drawn from.

Sample: a design studio (Atelier Nord) billing a coffee roaster. It deliberately exercises every field of the full data model — line-item detail, a returning-client discount, sales tax, a purchase-order number, a deposit already received, and the resulting balance due. The sheets stay on white paper in dark mode on purpose; only this page's chrome follows your theme.

Minimal · Swiss

Nordic

International-typographic restraint: a hairline grid, a spec-sheet metadata column, and generous air. Boldness spent in one place — the balance due, set large in signal red.

Production type: IBM Plex Sans (tight) · tabular figures

Classic · Serif

Sterling

The engraved letterhead of an old accounting house: a centered masthead framed by double rules, small-caps column heads, and a ruled table. Bottle green and a single restrained gold rule do the accenting.

Production type: Playfair Display · Source Serif 4 · sans for figures

Bold · Creative

Prism

A studio's invoice with a point of view: a solid teal brand rail carries the sender and an oversized wordmark, while the worksheet stays calm. The balance due lands in a coral chip — the one loud note.

Production type: IBM Plex Sans (heavy display) · Inter body

Structured · Corporate

Bureau

Built for finance departments: a boxed metadata grid, a fully ruled zebra table, and a filled totals panel. Monospaced tabular figures keep every column aligned; corporate blue flags status and balance.

Production type: Inter · IBM Plex Mono for figures

Demos are static mockups at true page proportions, using system fonts as stand-ins for the production faces named above. Once you approve a direction, the four become real templates in the builder — each editable, theme-variant-aware, and exported as a true-vector PDF.
